Design and prototype a premium, modern mobile fitness application called:

OMNI FITNESS AI

The app is an AI-powered personal fitness and nutrition companion. It helps users plan workouts, track exercise and nutrition, scan food using AI, create meal plans from ingredients they already have, track progress, and chat with an AI fitness coach.

Create a complete mobile-first UI/UX system and interactive prototype.

TARGET PLATFORM:
Mobile application designed for React Native / Expo.
Primary target: modern Android/iOS smartphone.
Use a clean mobile layout with touch-friendly controls.

DESIGN DIRECTION:
Create a premium, modern, minimal fitness-tech aesthetic.

The design should feel:
- Premium
- Athletic
- Intelligent
- Clean
- Modern
- Motivating
- Personalized
- Slightly futuristic because of the AI functionality

Avoid making it look like a generic bodybuilding app.

Use strong visual hierarchy, generous spacing, rounded cards, subtle shadows, modern typography, clear icons, and polished micro-interactions.

Create a consistent design system before designing the screens.

3. Clear hierarchy
4. Minimal clutter
5. Fast access to today's workout

9. Consistent components
